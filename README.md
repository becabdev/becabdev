### 🚌 MyBusFinder

A web app designed to make public transport easier to navigate.

- 🛰️ Track vehicles with **GTFS-Realtime** data.
- 🕒 Access theoretical schedules and service information.
- 🚧 Follow network disruption alerts.
- 🗺️ Explore routes on interactive **Leaflet** maps.
- 📱 Use a responsive interface on desktop and mobile.

**[Explore the repository →](https://github.com/becabdev/mybusfinder)** · **[Visit the project →](https://www.mybusfinder.fr/)**
